# Ecommerce is system e-commerce sell iphone for Onetechphone shop

# ▶️ Running the Project

## 1. Clone project

```bash
git clone https://github.com/HUU7911/Ecommerce.git
```

```bash
cd Ecomerce
```

---

## 2. Start Infrastructure

```bash
docker compose up -d
```

Kiểm tra:

```bash
docker ps
```

---

## 3. Build Project

Use Maven:

```bash
mvn clean install
```

Or:

```bash
./mvnw clean install
```

---

## 4. Run project

Run for Maven:

```bash
cd server
mvn spring-boot:run
```
